# Milestone 7 slice a access

The agent stays unprivileged. Add it to `systemd-journal` only if the distribution grants that group read access to the system journal. Confirm the grant with `journalctl --system --since '24 hours ago' -p err -o json` as the agent account. If the system journal is unreadable, the probe reports `unknown`; it does not silently report zero events. SSH and sudo counts also require journal access. No `sudo`, log file scraping, or privilege escalation is used by the agent.

The root helper's `/sensitive-files` endpoint returns path, size, mtime and SHA-256 for the fixed allowlist in `internal/helper/sensitive.go`. The helper reads file contents only to hash them, never returns contents, and rejects symlink files and directories. The Unix socket remains group restricted to `fleetglass`. The service uses `ProtectHome=read-only` so the fixed authorized-keys paths can be inspected; it does not write to `/home` or `/root`. The coordinator installs this unit after review.

Pending updates are derived from local APT package indexes and `/var/lib/dpkg/status`; no APT refresh or installation occurs. An unreadable or absent package index yields `unknown`. Reboot status comes from the existence of `/var/run/reboot-required`. Docker restart deltas require two samples to establish a baseline and cover the agent process lifetime. No host state is changed by these probes.

## Milestone 7 slice b access

Configure `backup_sets`, `status_files`, and `log_markers` in the same root-owned configuration read by the agent and helper. The helper exposes index-only `/backup/N`, `/status/N`, and `/log-marker/N` endpoints on its existing group-restricted Unix socket. It returns only state, generic detail, counts, age and size; status field values, log lines, backup names and file contents never leave the helper. The agent tries its own read first and uses the helper if the source is unreadable. Keep both configurations identical; unknown is reported if the helper cannot read the source. Backup patterns select regular files only, either as direct children of a configured directory or by glob; optional suffixes filter those files, and an optional warning age precedes the critical maximum age. Avoid broad patterns that would make the helper scan unrelated directories.

Repository roots and internal probe targets are configured on the agent. Roots contain repositories one directory deep. Git commands use local refs, disable optional locks, fsmonitor and hooks, and trust only the configured repository path; no fetch or index refresh write occurs. `local_only_repositories` prevents an absent upstream from marking an intentional local-only repository as a warning. HTTP probes make one GET without following redirects. Internal target addresses and paths are configured by the operator and should point only to trusted internal services. `worktree_roots` continues to drive the milestone 2 stale-worktree check.

Status file checks read one JSON scalar at `field_path`. Explicit `ok_values`, `warn_values`, and `crit_values` match its string form; an RFC 3339 timestamp means OK while it is within `max_age_seconds`. Other values and unreadable or stale files are unknown. `missing_state` may explicitly classify an absent file or field. The log-marker check reads at most the final 256 KiB and looks for a configured substring on lines beginning with an RFC 3339 timestamp; it returns no log text. These probes run at the five-minute cadence.
# Changes and energy (milestone 7c)

The unprivileged agent reads `/var/log/apt/history.log*` when its directory is readable, `/proc/stat` for boot time, and local Git history in configured repository roots. It reads selected unit events from journald; grant `systemd-journal` group membership to the agent only if journal access is needed. Neither Git nor APT collection runs an update or fetch command. Configured `log_markers` may set `change_event: true`; only the configured marker name and parsed timestamp enter the change journal. When the agent cannot read a configured marker log, the fixed helper endpoint `/log-marker-events/{index}` returns those two fields as typed events from that configured path only; it never returns a log line. Configure `energy_price_per_kwh` and `energy_currency` on the server (for example `0.2516` and `EUR`). RAPL is read directly or through the existing fixed `/rapl` helper endpoint.
