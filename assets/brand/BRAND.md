# Fleetglass brand

Chosen on 2026-10-08: mark "Glass panes" (direction A).

## Mark
Three rounded glass panes offset on a diagonal: each pane is a server of the fleet, the overlaps give the
glass shades. Built on a 64-unit grid: panes 28 x 28, corner radius 8, offset 9 units, opacities 40 %, 66 %, 100 %.

| File | Use |
|---|---|
| `mark.svg` | colour mark on light grounds |
| `mark-on-dark.svg` | colour mark on dark grounds (lighter gradient) |
| `mark-mono.svg` | single colour, follows `currentColor` |
| `app-icon.svg` | app icon and favicon: white panes on the brand gradient tile |
| `favicon.svg` | copy of `app-icon.svg` served as `/favicon.svg` |

- Clear space around the mark: one pane offset (9 units at 64 px, 14 % of the mark size).
- Minimum size: 16 px (favicon). Below 24 px prefer `app-icon.svg`.
- Do not rotate, recolour outside the palette, add effects or change the pane opacities.

## Wordmark
"Fleetglass" in Geist SemiBold, letter-spacing -0.035em, set to the right of the mark; the mark is 1.6x the cap
height. No all-caps.
