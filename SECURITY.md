# Security policy

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/thejoyfulist/fleetglass/security/advisories/new). Do not open a public issue with exploit details, tokens, host identifiers, or private data. Maintainers will acknowledge and coordinate a fix and disclosure through the advisory.

Fleetglass's trust boundaries, loopback defaults, token handling, and read-only helper are documented in [Security and privacy](docs/SECURITY.md). Supported versions are current releases; check the [releases page](https://github.com/thejoyfulist/fleetglass/releases) for the latest version.
