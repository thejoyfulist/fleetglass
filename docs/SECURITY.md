# Security and privacy

The agent and server run as the dedicated non-root `fleetglass` account. The small helper runs as root because SMART and selected file metadata may require privilege. Its Unix socket is group-restricted and every route accepts only a fixed, validated read. It has no write or command-execution API. Routes include indexed SMART and Docker reads, CPU package RAPL, allowlisted agent process metadata, fixed sensitive-file hashes, and indexed backup/status/log-marker observations; project and storage reads use configured roots. See `internal/helper/` for the exact allowlist. Host services, containers, files and processes are never modified.

The agent reads `/proc`, `/sys`, configured Docker sockets and local repositories. Optional `systemd-journal` membership is needed for system errors, SSH/sudo signals and unit events. Optional ACLs grant read/traverse access only to selected Claude Code and Codex session-log roots. Neither grant is automatic. Helper and agent outputs omit command lines, environments, secrets, MAC addresses, serial numbers and full public IPs. OTLP prompt bodies and arbitrary attributes are discarded. The database stores host identity, project/worktree names and paths, hashed session IDs, aggregate measurements and bounded recent error text. Treat it as private. Raw samples are kept seven days; hourly data 90 days; daily data two years, with domain-specific shorter or longer history as documented in the product specification.

The cockpit and OTLP receiver bind to loopback by default. Remote agent ingest requires HTTPS. A non-loopback cockpit bind requires a separate read token; MCP is disabled until explicitly given a loopback listener and its own token. `/metrics` uses cockpit read authentication. The optional public status listener serves only public probe summaries. Fleetglass has no analytics, third-party UI requests or automatic update check by default. Enabling `update_check_url` makes a daily HTTPS GET for release metadata without any installation identifier.

The MCP listener rejects HTTP Host names other than literal loopback addresses or `localhost`, as well as browser Origin headers. The tokenless OTLP listener applies the same Host check. The root helper caps SMART command output at 1 MiB before parsing it.

Builds require Go 1.26.9 or newer so distributed binaries include the security fixes in that standard-library release.
