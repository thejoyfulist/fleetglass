# Cockpit localization

The cockpit renders English or French from stable keys in `web/src/i18n.ts`. Call `t(key, params)` while rendering UI. Use `plural(count, oneKey, manyKey)` for counts. Every catalog key must have both languages and a call site; `web/src/i18n.test.ts` checks this. Technical terms that intentionally stay identical are listed in `unchangedTechnicalTerms`.

Keep observed data outside the catalog: host names, project and worktree names, unit and container names, package names, and journal messages. A source string is never translated by matching its English wording. Fleetglass-generated states and reasons use codes; the API keeps the legacy English fields while exposing `reason_code` for agent health, `detail_code` and optional `detail_params` for probe results, and `change_code` with `change_params` for change events. Existing stored rows receive presentation codes when read. Unknown codes show their raw detail or change text. Configured probes and log markers expose their display names; internal identifiers stay out of the UI.

Use the shared formatters in `web/src/data.ts` for dates, times, numbers, percentages, bytes, and durations. Both locales use 24-hour time. The selected language controls `Intl.NumberFormat` and `Intl.DateTimeFormat`.

Run `npm test` and `npm run build` in `web/`, then `python3 web/scripts/m9_i18n_visual.py` from the repository root. Set `FLEETGLASS_HEAVY_LOCK` to a lock file when sharing a machine with other test jobs.
